# 🩸 Blood Bank Management System

A web-based **Blood Bank Management System** built using **Python, Django, HTML, CSS, JavaScript, Bootstrap 5, and SQLite**. This application allows users to register as blood donors, search for available blood donors based on blood group and location, and contact the administration.

---

## 🚀 Features

- **🏠 Home Page:** Interactive carousel slider showcasing blood donation awareness.
- **🩸 Donor Registration:** Allows individuals to register as donors with their blood group, personal details, contact info, and medical history.
- **🔍 Search & Filter Donors:** Search donors by **Blood Group**, **State**, and **City** to find matching donors quickly.
- **📄 Donor Details View:** View comprehensive information about specific registered donors.
- **ℹ️ About Page:** Informative guide highlighting the benefits, procedures, and health guidelines for blood donation.
- **📞 Contact Us:** Enables visitors to send inquiries or messages directly to the bank.
- **🛡️ Admin Dashboard:** Django's built-in Admin panel to manage donors, contacts, and records.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, FontAwesome
- **Database:** SQLite3

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/blood-bank-management-system.git
   cd blood-bank-management-system
   ```

2. **Install Django:**
   ```bash
   pip install django
   ```

3. **Apply Database Migrations:**
   ```bash
   python manage.py migrate
   ```

4. **Create a Superuser (Admin):**
   ```bash
   python manage.py createsuperuser
   ```

5. **Run the Development Server:**
   ```bash
   python manage.py runserver
   ```

6. **Open in Browser:**
   - Web App: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   - Admin Panel: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
